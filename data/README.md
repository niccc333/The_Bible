# Data provenance

- File: `kjv.json`
- Source: https://raw.githubusercontent.com/churchstudio-org/openbible/main/KJV/bible.json
- Format: 3D JSON array `[book][chapter][verse]` of strings, 66 books in
  Protestant canonical order starting with Genesis.
- License: KJV text is public domain worldwide. The OpenBible repo that
  structures it is MIT-licensed. No proprietary translations are included.
- Verified at vendoring: 66 books, 1189 chapters, 31103 non-empty verses;
  `Genesis 1:1` = "In the beginning God created the heaven and the earth.",
  `John 3:16` starts "For God so loved the world".
